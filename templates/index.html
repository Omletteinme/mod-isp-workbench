HOW IT WORKS

From sensor mosaic
to restored image.

Each upload is decoded once, and the server then produces classical, learned and hybrid outputs from it. The figure traces two of them: the hybrid path through all four stages, and the classical baseline, which never uses the gate or the network.

  1. 01

    Decode

    RAW and RGGB NPY files become a normalized Bayer mosaic (black level, white balance), and camera RAW also gets a LibRaw render. Rendered images (JPEG, PNG, WebP, TIFF) stay RGB and never go to the Bayer model.

  2. 02

    Gate

    For the hybrid path, tiles are ranked and a fixed share goes to the network: by variance relative to brightness on Bayer data, by a high-frequency residual on rendered RGB. It is a compute budget, not a noise estimate. The learned path skips the gate and runs every tile.

  3. 03

    Neural

    Routed tiles run through the learned model: the 29,980-parameter Bayer student, or a fine-tuned NAFNet-lite denoiser for rendered images, which get exposure and tone mapping first.

  4. 04

    Finish

    Hybrid blends the network's tiles back into the classically denoised image with a smooth mask (on Bayer data the base is a plain demosaic), then applies the optional style and, on Bayer data, sharpening. The classical baseline tone-maps the image, denoises it with non-local means scaled to the estimated noise, and sharpens. When the network does not reduce an image's noise, Hybrid on a rendered image returns the classical result.
